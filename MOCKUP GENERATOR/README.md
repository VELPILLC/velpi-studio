# MOCKUP GENERATOR

Where design directions get explored. Nothing here is a real website yet —
these are single-file HTML mockups made to be looked at and judged.

## What goes in here

One folder per project:

    MOCKUP GENERATOR/
      pour-right-concrete/
        direction-a-motion.html      premium motion direction
        direction-b-still.html       premium still/advanced direction
        NOTES.md                     what each direction is doing and why

Every mockup is ONE self-contained .html file. Open it in a browser, no build
step, no server. That is the whole point — you should be able to judge it in
five seconds.

## The two directions

Every project gets explored both ways before anything is chosen:

- **Premium motion** — real movement. WebGL hero, scroll-driven reveals,
  Higgsfield-generated video or 3D. Heavier, more expensive to build, higher
  ceiling.
- **Premium still / advanced** — no ambient motion. Carries its weight through
  typography, composition, photography and restraint. Faster, safer, and the
  right answer for trust-driven niches (law, medical, funeral, accounting).

Neither is the default. Which one fits is a decision per business.

## Source material

`../design-inspiration/` — 1,610 reference templates (bootstrapmade, colorlib,
html5up, webflow notes), 9,500 icons (heroicons, lucide, tabler), plus palette,
font-pairing, animation and Three.js reference notes.

## When a direction is approved

It moves to `../SITE BUILDS/<project>/`. That transfer is the approval — if it
is still sitting here, it has not been chosen.
