# REFERENCE DROP

Put anything here you want Claude to learn from. No naming rules, no folders
to figure out — just drop it in and say "look in REFERENCE DROP".

## What works, best first

**1. The actual .html file of a site that does the effect.**
Far better than any tutorial. The technique is right there in the code and can
be read exactly, then rebuilt. Export it, save it here, done.

**2. A link to the site.** Live URLs can be fetched and read.

**3. Screenshots.** Images can be seen. Good for "make it look like this".
Grab the frame of the video where the effect is visible.

**4. Written notes.** .md or .txt. Even rough bullet points work.

**5. A link to the tutorial page** (not the video itself) — if there's a written
version or a CodePen, that reads fine.

## What does NOT work

**Video files (.mp4, .mov).** They cannot be watched. Nothing can be pulled out
of them. Don't spend time uploading them.

The workaround costs you 10 seconds: pause the video on the frame that shows the
effect, screenshot it, drop the image here. If the video mentions a library or a
technique by name, type that name into a note. That is enough to rebuild from.

## What happens next

Anything dropped here gets turned into a reusable recipe in
`../design-inspiration/3d-effects/` so it is available for every future build,
not just the one being worked on.
