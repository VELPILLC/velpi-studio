## 1. PROJECT OVERVIEW

Velpi Studio is a Next.js 14 App Router web app for building Facebook ad creatives.
It uses an AI assistant called **Jarvis** (powered by Claude claude-sonnet-4-5) to guide users through a step-by-step ad creation flow.
Ads and audience avatars are stored in Supabase.
Images are generated by OpenAI gpt-image-1.

The app is deployed on Vercel.
The GitHub repo is at: `https://github.com/VELPILLC/velpi-studio`

```

font-bebas   → var(--font-bebas-neue)
```

### Usage conventions

- **IBM Plex Mono** is the UI language font — all labels, section headers, tags, buttons, and metadata use it

- **Bebas Neue** is used only for modal/dialog titles
- **Barlow Condensed** is used only in the content frame image overlay headline
- Font sizes: labels use `0.48rem–0.6rem`; body copy uses `0.8rem–0.85rem`; display uses `1.3rem–1.4rem`

### Rendering logic

- Header is `position: sticky; top: 0; height: 52px; z-index: 100`
- Tab bar is `position: sticky; top: 52px; z-index: 99`
- Tab content is in a `padding: 1.5rem; maxWidth: 1200px; margin: 0 auto` wrapper

### Studio state

| State | Initial | Purpose |
|---|---|---|
| `activeTab` | `'ads'` | Controls which tab is rendered |
| `pendingRefine` | `null` | Ad object passed from LibraryTab → AdsTab for refinement |

### Cross-tab communication

When user clicks **Refine** on an ad in LibraryTab:
1. `handleRefineFromLibrary(ad)` is called on Studio
2. `setPendingRefine(ad)` stores the ad
3. `setActiveTab('ads')` switches to AdsTab
4. AdsTab receives `pendingRefine` prop and calls `loadForRefine(ad)` via `useEffect`
5. `onRefineConsumed()` callback clears `pendingRefine` after loading

```
version_number→ versionNumber
parent_id     → parentId
```

Also preserves existing camelCase fields if already present (handles both formats).

## 12. ADSTAB DEEP DIVE

File: `components/tabs/AdsTab.js`
**Type:** Client component (`'use client'`)
**Role:** Full ad creation flow driven by Jarvis (Claude). Avatar management, step-by-step bubble selection, image generation, save to library.

---

### Constants

#### `JARVIS_SYSTEM_PROMPT`

Defines Jarvis as a direct-response ad strategist. Key rules:
- Never assume industry, audience, product, or offer
- Never invent numbers, stats, claims, or proof
- Framework: Avatar → Pattern Interrupt → Identity Call-Out → Emotion → Copy Rules
- Returns JSON only, never plain text
- Step response format for each of: `avatar`, `visual_format`, `hook`, `image_concept`, `headline`, `primary_text`, `description`, `cta`
- `refinementCount` controls option count: 0=5, 1=3, 2=2, 3+=3 variations

#### `NEXT_STEP`

Maps each step to the next step in the flow:
```
avatar → visual_format → hook → image_concept → headline → primary_text → description → cta → done
```

#### `STEP_LABELS`

Human-readable labels for each step key:
```
avatar       → 'AVATAR'
visual_format→ 'VISUAL FORMAT'
hook         → 'HOOK'
image_concept→ 'IMAGE CONCEPT'
headline     → 'HEADLINE'
primary_text → 'PRIMARY TEXT'
description  → 'DESCRIPTION'
cta          → 'CALL TO ACTION'
done         → 'DONE'
```

#### `PANEL_FIELD`

Maps step keys to the corresponding `adPanel` state field:
```
avatar       → 'avatar'
visual_format→ 'visualFormat'
hook         → 'hook'
image_concept→ 'imageConcept'
headline     → 'headline'
primary_text → 'primaryText'
description  → 'description'
cta          → 'cta'
```

#### `EMPTY_PANEL`

Default state for the right-column ad panel:
```js
{ avatar:'', visualFormat:'', hook:'', imageConcept:'', imageB64:'', 
  imageLoading:false, headline:'', primaryText:'', description:'', cta:'' }
```

#### `EMPTY_AVATAR_FORM`

Default state for the avatar edit form:
```js
{ name:'', age_range:'', niche:'', what_they_want:'', 
  what_they_fear:'', what_they_trust:'', primary_emotion:'' }
```

#### `AVATAR_QUESTIONS`

The five hardcoded questions Jarvis asks sequentially in the avatar builder chat:
```
1. "Who do you sell to? Just describe them like you would to a friend."
2. "How old are they roughly?"
3. "What is the one thing they complain about most?"
4. "What do they want more than anything?"
5. "What would make them stop scrolling on Facebook?"
```

No API calls during the 5-question phase — questions are shown locally, one at a time.

#### `AVATAR_BUILDER_SYSTEM`

System prompt for the synthesis API call after all 5 answers are collected:
- Extracts a JSON avatar object with fields: `suggested_name`, `age_range`, `niche`, `what_they_want`, `what_they_fear`, `what_they_trust`, `primary_emotion`, `_done: true`
- Returns JSON only, nothing else

### Functions

#### Data loading

**`loadAvatars()`**
- Fetches `GET /api/avatars`
- Sets `avatars` state
- Called on mount via `useEffect`

#### Avatar management (edit modal)

**`handleSaveAvatar()`**
- If `avatarModal.mode === 'edit'`: `PATCH /api/avatars` with `{ id, ...avatarForm }`
- If `mode === 'create'` (legacy — no longer triggered by UI): `POST /api/avatars` with `avatarForm`
- After save: `loadAvatars()`, auto-selects new avatar if creating, closes modal, resets form

**`openEditAvatar(av)`**
- Populates `avatarForm` from avatar object
- Sets `avatarModal` to `{ mode: 'edit', data: av }`
- Triggered by the ✎ edit icon next to each avatar card

#### Avatar builder (Jarvis chat flow)

**`handleAvatarBuilderSend()`**
- Reads `avatarBuilder.input` as the user's answer
- Appends user bubble to messages
- If `questionIdx < 4`: shows next hardcoded question as AI bubble, increments `questionIdx`
- If `questionIdx === 4` (all 5 answers collected):
  - Sets `loading: true`
  - Builds `contextMessages` array from all 5 Q&A pairs (role: `assistant`/`user`)
  - Calls `POST /api/chat` with `AVATAR_BUILDER_SYSTEM` and `contextMessages`
  - Parses JSON response (strips ` ```json ``` ` fences)
  - Appends summary AI bubble: `"Got it. Here is your avatar.\n{name} — {niche}"`
  - Sets `extracted` and `editName` from parsed JSON

**`handleSaveBuiltAvatar()`**
- Posts `POST /api/avatars` with all extracted fields + `editName` as `name`
- Calls `loadAvatars()`, auto-selects new avatar, closes builder modal

#### Ad building flow

**`buildMessages(hist)`**
- Converts `history` array into Anthropic messages format
- User items: `{ role: 'user', content: item.text }`
- Jarvis items: `{ role: 'assistant', content: JSON.stringify({ step, options, sub }) }`

**`parseJarvisResponse(raw)`**
- Primary: strip ` ```json ``` `, parse JSON, check for `step` field
- Fallback: regex match `{...}` containing `"step"`, parse that
- Returns parsed object or `null`

**`getLastJarvisTurnIdx(hist)`**
- Returns index of the most recent Jarvis history item
- Used to determine which bubble set is currently interactive

**`callAPI(chatHistory, refCount)`**
- Posts to `/api/chat` with `messages`, `system: JARVIS_SYSTEM_PROMPT`, `refinementCount`, and `avatar: selectedAvatar || null`
- Returns raw response text

**`generateImage(concept)`**
- Posts to `/api/image` with full prompt: `"cinematic 9:16 vertical photo, {concept}, no text, no logos, photorealistic, documentary style"`
- Sets `adPanel.imageLoading` true during generation
- Sets `adPanel.imageB64` on success

**`handleIdeaSubmit()`**
- Takes `input` text, adds user bubble to history, calls `callAPI`, appends Jarvis response
- Resets `input` to `''`
- Triggered when `currentStep === 'idea'` and user sends

**`handleBubbleClick(opt)`**
- Toggles `opt` in `selectedBubbles` array
- If already in array: removes it
- If not in array: appends to end (last element = "most recently selected")

**`handleRefine()`**
- Sends a refinement message like: `'I'm leaning toward "X", "Y" for HOOK. Return 3 tighter options...'`
- Increments `refinementCount`
- Clears `selectedBubbles`
- Refine button is hidden when `refinementCount >= 2`
- Option count decreases: first refine → 3, second → 2

**`handleConfirm()`**
- Takes `selectedBubbles[selectedBubbles.length - 1]` as the confirmed value
- Calls `lockBubble(value)`

**`lockBubble(value)`**
- Sets the corresponding `adPanel` field
- Triggers `generateImage` if step is `image_concept`
- Marks the last Jarvis turn as locked with the chosen value
- Advances to next step: sends advance message `'HOOK: "value"'` to Claude, gets next step options
- If next step is `'done'`: sets `currentStep = 'done'`, stops

**`loadForRefine(ad)`**
- Resets conversation with a "refine" prompt containing original ad fields
- Resets `currentStep` to `'hook'`, clears bubbles and refinementCount
- Loads existing ad fields into `adPanel` (handles both camelCase and snake_case)
- Calls Claude to get 5 new hook options

**`resetAd()`**
- Clears `history`, `adPanel`, `selectedBubbles`, `refinementCount`, `customBubble`, `input`
- Resets `currentStep` to `'idea'`

**`saveToLibrary()`**
- Posts `POST /api/library` with all `adPanel` fields + avatar context
- On success: sets `saveSuccess = true`, auto-clears after 2000ms (toast)

## 13. API ROUTES

### `POST /api/chat` — `app/api/chat/route.js`

**Purpose:** Sends a conversation to Claude claude-sonnet-4-5 and returns the response text.

**Request body:**
```json
{
  "messages": [{ "role": "user|assistant", "content": "string" }],
  "system": "optional system prompt override",
  "refinementCount": 0,
  "avatar": null
}
```

**Behavior:**
1. If `avatar` is provided and has a `name` field, prepends two messages at the START of the messages array:
   - User message: `AVATAR CONTEXT — write everything for this person: Name: ... Age Range: ... Niche: ... What they want: ... What they fear: ... What they trust visually: ... Primary emotion: ...`
   - Assistant message: `{"step":"ready","message":"Avatar locked in. I know exactly who we are writing for."}`
2. Appends `[refinementCount: N]` to the content of the last user message
3. Calls `client.messages.create` with model `claude-sonnet-4-5`, `max_tokens: 2000`

**Response:**
```json
{ "text": "raw response string" }
```

**Error response:**
```json
{ "error": "message" }   // status 500
```

**Notes:**
- Anthropic SDK is dynamically imported inside the handler to avoid module-level instantiation errors
- Default system prompt is `JARVIS_SYSTEM` (defined in the route file) if no `system` is passed
- The `JARVIS_SYSTEM` in the route file is a shorter/older version of the system prompt; the full psychology framework prompt is `JARVIS_SYSTEM_PROMPT` in AdsTab.js and is always passed explicitly

---

### `POST /api/image` — `app/api/image/route.js`

**Purpose:** Generates an image via OpenAI and returns base64.

**Request body:**
```json
{ "prompt": "string" }
```

**Behavior:**
- Calls `openai.images.generate` with model `gpt-image-1`, size `1024x1792`, quality `standard`, `n: 1`
- Returns `b64_json` from the first result

**Response:**
```json
{ "b64": "base64string" }
```

**Notes:**
- OpenAI SDK is dynamically imported inside the handler
- AdsTab.js sends the prompt as: `"cinematic 9:16 vertical photo, {concept}, no text, no logos, photorealistic, documentary style"`
- ContentTab.js sends the raw `dalle_prompt` from the generated content JSON

## 17. PRINT / EXPORT BEHAVIOR

- Triggered by `window.print()` from the "Export PDF" button in AdsTab right column

- User prints to PDF via browser print dialog

### Canvas Export (Content tab)

- Triggered by the "Save" button in ContentTab
- Uses `window.html2canvas` (loaded from CDN) to screenshot `#content-frame`
- Renders at `scale: 2` for retina quality
- Downloads as `velpi-content.png` via programmatic link click
- `html2canvas` is loaded lazily (`strategy="lazyOnload"`) in `app/layout.js`
