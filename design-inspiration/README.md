# Design Inspiration Reference Library

Reference material for Velpi Studio's generator — collected 2026-08-13. Reference
only: never modify template files, never ship their demo images in client work.

- **[pattern-library.md](pattern-library.md)** — the synthesis: recurring premium
  patterns (heroes, navs, cards, CTAs, section flow, spacing) framed for our stack,
  plus the per-source license ledger. **Start here.**
- **templates/**
  - `html5up/` — 8 templates (CC-BY 3.0, attribution required if reused)
  - `bootstrapmade/` — 8 templates (free license, footer credit required)
  - `colorlib/` — 8 Bootstrap 6 templates from official ColorlibHQ GitHub (MIT) —
    see `colorlib/LICENSE-NOTES.md`
  - `webflow-notes/` — 8 observation write-ups of top Webflow templates (no downloads)
  - `TEMPLATEMONSTER-NOTE.md` — why TemplateMonster is absent (login-walled)
- **fonts/font-pairings.md** — 25 Google Fonts pairings by business vibe
- **icons/** — Lucide (ISC), Tabler (MIT), Heroicons (MIT) full SVG sets + `icons.md`
  niche index (all inline-SVG-usable, no attribution required)
- **colors/palettes.md** — 28 palettes by niche/mood with 60/30/10 + dark variants
- **animations/animations.md** — GHL-safe animation catalog (transform/opacity only,
  vanilla JS/CSS, working code)
- **3d-effects/threejs-inspired.md** — Three.js-style ambient effects (gradient mesh,
  particle fields, liquid blobs, orbiting elements, holographic sheen) rebuilt as
  pure-CSS recipes — no WebGL, no external library, no JS at all
