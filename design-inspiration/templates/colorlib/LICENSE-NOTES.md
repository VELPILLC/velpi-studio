# Colorlib templates — source & license notes

**Source:** official Colorlib GitHub repository
https://github.com/ColorlibHQ/bootstrap-templates (cloned 2026-08-13).

**License: MIT** (Copyright (c) 2026 Colorlib) — free for commercial use, no
attribution required. A copy of the repo LICENSE is kept inside each template folder.

Why GitHub and not colorlib.com downloads: the zip downloads on
colorlib.com/wp/template/* now go through an Easy Digital Downloads checkout
(account/email wall), and those site-distributed templates are licensed **CC BY 3.0**
(footer attribution required). The official GitHub repo distributes Colorlib's own
Bootstrap 6 template collection freely under MIT — a strictly better license for our
purposes — so the library uses that channel. No walls were bypassed.

All templates are self-contained (no build step, no references outside their folder).
Bootstrap 6 based.
